# Install Godot Launcher {#installation}

Download Godot Launcher from the official [download page](https://godotlauncher.org/download). Choose the package for Windows, macOS, or Linux, then follow the platform instructions below.

For older versions or a specific installer file, see [Godot Launcher releases on GitHub](https://github.com/godotlauncher/launcher/releases).

## Install

### Windows

<div className="platform-download-panel">
  <div className="platform-download-panel__details">
    <strong className="platform-download-panel__title">Windows installer</strong>
    <span className="platform-download-panel__meta">Windows 10 or later. Choose x64 for most PCs or ARM64 for Windows on ARM.</span>
    <span className="platform-download-panel__file"><code>Godot_Launcher-x.y.z-win_x64.exe</code> or <code>Godot_Launcher-x.y.z-win_arm64.exe</code></span>
  </div>
  <a className="button button--primary" href="https://godotlauncher.org/download">Download Windows installer</a>
</div>

1. Download the `.exe` for your processor.
2. Open the installer and follow the steps on screen.
3. Start Godot Launcher from the installer or the Start menu.

#### Check Windows release signing {#windows-release-signing}

Windows installers are code signed through [SignPath.io](https://signpath.io/), with a certificate from the [SignPath Foundation](https://signpath.org/). See [Troubleshooting](../troubleshooting.md#installation-and-startup) if Windows blocks or warns about the installer.

### Linux

<div className="platform-download-panel">
  <div className="platform-download-panel__details">
    <strong className="platform-download-panel__title">Linux packages</strong>
    <span className="platform-download-panel__meta">Choose AppImage, <code>.deb</code>, or <code>.rpm</code> for x64 or ARM64. The examples below use x64 filenames.</span>
  </div>
  <a className="button button--primary" href="https://godotlauncher.org/download">Choose a Linux package</a>
</div>

In the commands below, replace `x.y.z` with the downloaded version and run the command from the folder containing the file. For ARM64, use the downloaded `arm64` filename.

#### AppImage

:::info FUSE is required for AppImage
If the AppImage reports a FUSE error, follow the [AppImage FUSE instructions](https://docs.appimage.org/user-guide/troubleshooting/fuse.html) for your distribution, or use the `.deb` or `.rpm` package.
:::

Make the downloaded file executable:

```bash
chmod +x Godot_Launcher-x.y.z-linux_x64.AppImage
```

Then double-click the file or run:

```bash
./Godot_Launcher-x.y.z-linux_x64.AppImage
```

#### Debian / Ubuntu (.deb)

Install the `.deb` from the download page:

```bash
sudo apt install ./Godot_Launcher-x.y.z-linux_x64.deb
```

#### Fedora / RHEL (.rpm)

Install the `.rpm` from the download page:

```bash
sudo dnf install ./Godot_Launcher-x.y.z-linux_x64.rpm
```

After installing a `.deb` or `.rpm`, open Godot Launcher from your application menu.

## Complete first-run setup

On the first run, complete four steps to set up the launcher for your workflow.

<ThemedImage
  className="docs-media-frame"
  alt="Godot Launcher Welcome screen showing the four first-run setup steps"
  sources={{
    light: '/img/screenshots/screen_onboarding_welcome_light.webp',
    dark: '/img/screenshots/screen_onboarding_welcome_dark.webp',
  }}
/>

1. **Welcome** introduces the setup.
2. **Appearance** lets you choose the launcher theme.
3. **Setup** confirms the project and editor locations and lets you choose a default code editor. On Windows, you can also enable editor symlinks to reduce disk use.
4. **Preferences** lets you choose what happens after opening a project. On Windows and macOS, you can also choose whether the launcher starts with your computer.

Select **Finish and view projects** to open Projects, even when no Godot editor
is installed. From there, [create a project](../projects/create-project.mdx) and
choose an editor to download, or [add existing work](../projects/add-existing-project.mdx).

:::info Change setup choices later
Godot Launcher uses your operating system language when a matching translation is available. Change it later under **Settings > Appearance > Language**. The other setup choices remain available in [Godot Launcher Settings](../settings/launcher-settings.mdx), [Code Editor Settings](../settings/code-editors.mdx), and [Behaviour settings](../settings/behavior.mdx).
:::

For package or startup problems, see [Installation and startup troubleshooting](../troubleshooting.md#installation-and-startup). For Linux tray problems, see [System tray troubleshooting](../troubleshooting.md#system-tray).
