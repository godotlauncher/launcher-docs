# Installing Godot Launcher with winget

You can install, update, and remove Godot Launcher from PowerShell or Command Prompt with [winget](https://learn.microsoft.com/windows/package-manager/). The package ID is `GodotLauncher.Launcher`.

---

## Requirements

- Windows 10 version 1809 (build 17763) or later, or Windows 11.  
- The **App Installer** package from the Microsoft Store, which provides the `winget` client.  

Run `winget --info` to check whether winget is available. If it is missing, install or update [App Installer](https://apps.microsoft.com/detail/9nblggh4nns1) through the Microsoft Store. See Microsoft's [WinGet installation guidance](https://learn.microsoft.com/windows/package-manager/winget/#install-winget) if winget is still unavailable.

---

## Install the latest release

<WingetCommandList
  commands={[
    {
      label: "Install Godot Launcher",
      command: "winget install --id GodotLauncher.Launcher --exact --source winget",
    },
  ]}
  intro="Run this command to install the latest Godot Launcher version available from the winget source:"
/>

Follow any agreement or administrator prompts. After installation, open **Godot Launcher** from the Windows Start menu.

---

## Keep Godot Launcher updated

<WingetCommandList
  commands={[
    {
      label: "Check available updates without installing",
      command: "winget upgrade",
    },
    {
      label: "Install the Godot Launcher update",
      command: "winget upgrade --id GodotLauncher.Launcher --exact --source winget",
    },
  ]}
  intro="First list the available updates and look for GodotLauncher.Launcher. Run the second command when you want to install its update."
/>

The [upgrade command](https://learn.microsoft.com/windows/package-manager/winget/upgrade) without arguments lists available updates. Adding a package name or ID asks winget to install that package's update.

**No applicable update found** means winget found no applicable update in the selected source. A newer release may be published on [GitHub](https://github.com/godotlauncher/launcher/releases) before it becomes available through winget.

---

## Discover other manifest details

- `winget show --id GodotLauncher.Launcher --exact --source winget` shows the available version and installer details.
- `winget list --id GodotLauncher.Launcher --exact` shows the installed version recognised by winget.

---

## Uninstall or reinstall

Run `winget uninstall --id GodotLauncher.Launcher --exact --source winget` to remove Godot Launcher.

To reinstall, wait for the uninstall to finish, then run the [install command above](#install-the-latest-release). The `--silent` option only hides installer UI; it does not request a reinstall.

---

## Troubleshooting tips

- If winget cannot find the package, run `winget source update --name winget`, then retry.
- If the Microsoft Store or App Installer is restricted on a managed device, ask your administrator about installing winget, or use the [Windows installer](../getting-started/installation.mdx#windows).

Run `winget --open-logs` to find diagnostic logs. Before sharing a log in an issue, remove personal paths, account names, and credentials. Include the command you ran and its error message.
