# Project Tags

Use tags in Godot Launcher to organise projects by status, purpose or event.
Tags belong to the launcher on this computer; they do not change your Godot project files.

## Add tags to a project

Select the tag icon beside a project name in Cards or List view. The picker
shows the project's current tags and other available tags.

- Select an existing tag, or type a name and select **Create**.
- Select the cross on a tag to remove it from this project.
- Select a coloured dot to choose from 30 colour presets.

Changes made here save immediately. Tag names and colours are shared: changing
a colour updates that tag everywhere it is used. Removing a tag from one
project keeps it available for other projects.

The project row shows up to three colour dots and a count of additional tags.
Hover over the tag icon to see their names. The icon remains available when a
project has no tags.

You can also open **Project Settings > Project > Tags**. Changes made in
Project Settings are saved with **Update**; **Discard** leaves them unchanged.

## Filter projects by tag

Open **Tags** beside Search and select one or more tags. Projects matching
**any** selected tag remain visible. A text search narrows those results
further. Tag filters are remembered when you close and reopen the app.

Remove individual filter pills or select **Clear tags** to show all tags again.
When there are no results, **Clear filters** clears both the tag selection and
text search. Clear search and tag filters before reordering pinned projects.

In the Projects view, use **Cmd+T** on macOS or **Ctrl+T** on Windows and Linux
to open the tag filter. Use **Cmd+K** or **Ctrl+K** to focus Search.
These shortcuts do not interrupt an open settings drawer or another picker.

In a tag picker, use the arrow keys to choose an option, **Enter** to select
it, and **Escape** to close it.

## Manage shared tags

Open **Settings > Projects > Manage tags** to see all tags, including unused
ones. The count beside each tag shows how many projects use it.

- Enter a name and select **Add** to create a tag without assigning it.
- Select the pencil to rename a tag. Confirm with the tick or **Enter**, or
  cancel with the cross or **Escape**.
- Select the coloured dot to change its colour immediately.
- Select the bin to delete a tag. The confirmation shows the affected-project
  count. Deletion removes that tag from every project.

Names cannot be blank or duplicate another tag, ignoring letter case.
Deleting a selected filter removes that tag restriction while keeping other
selected tags. Deleting the last selected tag removes the tag restriction.

## If a change fails

If tags cannot be loaded, select **Retry**. If saving fails, check the error
and try the change again. An unsuccessful save does not replace the saved tag
selection. A failed rename keeps the entered name available to retry.
