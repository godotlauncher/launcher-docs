# Organise Projects with Tags {#project-tags}

Use tags in Godot Launcher to organise projects by status, purpose or event.
Tags are saved on this computer and do not change your Godot project files.

## Add tags to a project

Select the tag icon beside a project name in **Cards**, **Compact** or **List** view.
Up to three coloured dots appear beside the name, followed by a count of any
additional tags. Hover or focus the tag control to see all assigned tags.

- Select an existing tag, or type a name and select **Create**.
- Select the cross on a tag to remove it from this project.
- Select a coloured dot to change the tag's colour across all projects that use it.

Changes save immediately. Removing a tag from a project keeps it available
for other projects.

## Choose tags before adding a project

Use the tag icon beside the project name when creating or duplicating a project,
or while reviewing projects imported from this computer, Godot Project Manager,
a folder, GitHub or a public Git repository. A duplicate starts with the source
project's tags; you can change them for the copy without changing the source.

For several imported projects, select their checkboxes and open **Tag selected**
above the list. Use **Select all projects** to include every available project.
The number on the button shows how many projects the tag changes will affect.

- An unchecked tag is added to all selected projects.
- A mixed tag is added to the selected projects that do not yet have it.
- A checked tag is removed from all selected projects.

Other tags keep their assignments. You can still use each project's tag icon to
make individual changes. Projects selected afterwards do not inherit earlier
bulk tag changes.

These choices are saved when the project is successfully created or added.
Closing the form or cancelling review discards unsaved tag choices. Importing
several projects saves tags only for those added successfully.

If tags cannot be saved, the project remains added. Select **Retry** to save its
tags again without recreating or importing the project. **Cancel** continues
without retrying; you can edit tags from **Projects** later.

## Edit tags for several projects

1. In **Projects**, select **Enable multi-select** and choose projects using their checkboxes or the group checkboxes.
2. Open **Actions > Bulk edit tags**.
3. Search for a tag, then select its checkbox to change its assignment.

The tag editor shows membership across the selected projects:

| Checkbox | Current assignment | Selecting it does this |
| --- | --- | --- |
| Unchecked | None of the selected projects use the tag. | Adds it to all selected projects. |
| Mixed | Some selected projects use the tag; the count shows how many. | Adds it to the remaining projects. |
| Checked | All selected projects use the tag. | Removes it from all selected projects. |

Each change saves immediately. Tags you do not change keep their existing
assignments. Type a new tag name and select **Create** to create and assign it to
the selected projects. Close the editor or press <kbd>Escape</kbd> when finished;
closing keeps saved changes.

The editor keeps the same target projects and membership total while open, even
when a tag change hides a project under the current filter. Closing the editor
removes hidden projects from the selection. Changing project **Search** or the
**Tags** filter closes the editor and clears selection; searching inside the tag
editor does not.

If a change partly fails, successful changes remain saved. The **Tags**
notification names failures and offers **Retry** for only those targets, using
the original add or remove action. Projects removed elsewhere are reported as
unavailable and are not replaced by newly matching projects.

For tag names, colours, or deletion, use [Manage tags](#manage-shared-tags).
See [Select several projects](./manage-projects.mdx#select-several-projects) for
selection and the other bulk actions.

## Filter projects by tag

Open **Tags** beside Search and select one or more tags. Projects matching
**any** selected tag remain visible. A text search narrows those results
further. Tag filters are remembered when you close and reopen the app.

Select the cross beside a selected tag to remove it from the filter, or select
**Clear tags** to remove all tag filters. Any text search still applies.
When there are no results, **Clear filters** clears both the tag selection and
text search.

## Manage tags {#manage-shared-tags}

Open **Settings > Projects > Manage tags**. The number beside each tag shows
how many projects use it.

- Enter a name and select **Add** to create a tag.
- Select the pencil to rename a tag, then the tick to save it.
- Select the coloured dot to change its colour.
- Select the bin, then confirm with **Delete** to delete a tag.

Name and colour changes apply everywhere the tag is used. Deleting a tag
removes it from every project.

## Keyboard shortcuts

In the **Projects** view:

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| Open the tag filter | **Cmd+T** | **Ctrl+T** |
| Focus Search | **Cmd+K** | **Ctrl+K** |

In a tag picker, use the arrow keys to choose an option, **Enter** to select
it, and **Escape** to close it.
