# Behaviour Settings {#behavior-settings}

Open **Settings > Behavior** to choose what happens when you close the Godot Launcher window or open a project, change startup settings, or control project removal confirmation. On Windows, this tab also provides optional editor symlinks.

## Confirm project removal

Enable **Ask for confirmation when removing projects.** to show a confirmation before a project is removed from the list. This option is enabled by default.

Removing a project leaves its project folder on disk. Godot Launcher removes the project entry and its prepared editor files or links.

## Choose what happens when closing the window

Under **Window Close**, choose what happens when you close the launcher window:

- **Close to system tray**: hide the window and keep Godot Launcher running in the tray. This is the default.
- **Quit Godot Launcher**: stop the application completely.

Your choice is saved automatically. This setting is separate from **Project Launch Action** below.

If no usable tray is available, closing the window quits Godot Launcher even when **Close to system tray** is selected. During initial setup, closing the window also quits the application.

## Choose what happens after opening a project

Under **Project Launch Action**, choose what Godot Launcher does after it opens a project:

- **Nothing**: keep the launcher window visible.
- **Minimize**: minimise the launcher window.
- **Close to system tray**: hide the launcher window and keep it available from the tray. This is the default.

If a usable tray is unavailable, **Close to system tray** leaves the window visible. See [System Tray](./system-tray.mdx) to reopen the window or launch a recent project.

## Save space with editor links on Windows

Under **Editor symlinks** on Windows, Godot Launcher can create symbolic links to installed editors instead of keeping a copy in each project's separate editor environment. These environments are under the editor install location, outside the Godot project folders. This option is off by default.

This can reduce disk usage, but Windows may require Developer Mode or administrator approval depending on your system. If link creation fails, the launcher falls back to copying the editor.

The setting is used the next time the launcher prepares an editor for a project. Existing projects keep their current setup until you change or reinstall their Godot editor.

See [Godot Launcher Symlink Support on Windows](../platform/windows-symlink.md) before enabling this option.

## Start the launcher with your computer

On Windows and macOS, use **Startup Preference** to start Godot Launcher automatically when you sign in:

1. Enable **Start when computer starts.**
2. To keep the main window hidden, enable the nested **Start in tray.** option.

Both options are enabled by default. **Start in tray.** is available only while automatic startup is enabled.

Automatic startup is not supported by Godot Launcher on Linux. For tray availability problems, see [System tray troubleshooting](../troubleshooting.md#system-tray).
