# Godot Launcher Settings

Open **Settings** to configure Godot Launcher. Choose storage locations, change the appearance and behaviour, set up development tools and GitHub connections, or manage launcher updates.

## Set up projects {#projects-tab}

The **Projects** tab lets you choose the [default folder for new projects](./project-location.mdx)
and [manage project tags](../projects/project-tags.mdx#manage-shared-tags).

## Choose where Godot editors are stored {#installs-tab}

The **Installs** tab controls where downloaded Godot editors are stored and lets you refresh the release list.

[Godot Editor Install Location](./editor-installs-location.mdx)

## Choose where export templates are stored {#export-templates-tab}

The **Export Templates** tab shows the storage locations for official and imported custom templates. Use it to move template storage and review the required disk space. These locations are separate from the editor install location.

[Move template storage](../editors/export-templates.mdx#move-template-storage)

## Change appearance and language {#appearance-tab}

The **Appearance** tab controls the launcher theme and interface language. These settings affect Godot Launcher only; they do not change the language of the Godot editor.

[Appearance and Language Settings](./appearance-language.mdx)

## Change launcher behaviour {#behavior-tab}

The **Behavior** tab controls confirmation prompts, what happens after launching a project, automatic startup, and optional editor symlinks on Windows.

[Behaviour Settings](./behavior.mdx)

## Set up code editors {#code-editors-tab}

The **Code Editors** tab finds Visual Studio Code and VSCodium. Use it to choose which editors projects can use, set the default for new projects, rescan an installation, or choose an editor's location.

[Code Editor Settings](./code-editors.mdx)

## Manage connections {#connections-tab}

The **Connections** tab manages GitHub connections and repository access. Connect an account to import accessible repositories, including private ones, or publish a new project to GitHub. Public Git repository imports do not require a connection.

[Connections](./connections.mdx)

## Set up development tools {#tools-tab}

The **Tools** tab manages Git, Git LFS, and terminal detection. Use it to rescan installed tools, configure a terminal, and manage your Git identity or a preset for new repositories.

[Development Tools](./tools.mdx)

## Manage launcher updates {#updates-tab}

The **Updates** tab controls background update checks, beta updates, manual checks, skipped versions, and update installation prompts.

[Manage Godot Launcher Updates](../updates/manage-launcher-updates.mdx)
