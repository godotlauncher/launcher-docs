# Godot Launcher Settings

Use **Settings** in Godot Launcher to choose where projects, editors and export templates are stored, change the appearance and behaviour, set up development tools, and manage updates.

This page is the settings overview. Each section links to a focused guide with the details for that settings area.

## Choose where new projects are stored {#projects-tab}

The **Projects** tab controls the default folder used for new projects created through Godot Launcher. Existing projects are not moved when this path changes.

[Project Location Settings](./project-location.mdx)

## Choose where Godot editors are stored {#installs-tab}

The **Installs** tab controls where downloaded Godot editors are stored and lets you refresh the release list.

[Editor Install Location Settings](./editor-installs-location.mdx)

## Choose where export templates are stored {#export-templates-tab}

The **Export Templates** tab shows separate storage locations for Official and imported custom templates. Use **Move** to choose a destination and review the data size and available space. Close Godot editors and stop exports before moving templates.

Moving Official storage keeps a connection at Godot's default template path. Changing the editor install location does not move these files.

[Move template storage](../editors/export-templates.mdx#move-template-storage)

## Change appearance and language {#appearance-tab}

The **Appearance** tab controls the launcher theme and interface language. These settings affect Godot Launcher only; they do not change the language of the Godot editor.

[Appearance and Language Settings](./appearance-language.mdx)

## Change launcher behavior {#behavior-tab}

The **Behavior** tab controls confirmation prompts, what happens after launching a project, startup behavior, and optional Windows editor symlink behavior.

[Behavior Settings](./behavior.mdx)

## Set up code editors {#code-editors-tab}

The **Code Editors** tab finds Visual Studio Code and VSCodium. Use it to choose which editors projects can use, set the default for new projects, rescan an installation, or choose an editor's location.

[Code Editor Settings](./code-editors.mdx)

## Manage connections {#connections-tab}

The **Connections** tab connects GitHub to Godot Launcher and manages the GitHub App installations available for repository import. Public Git repository imports do not require a connection.

[Connections](./connections.mdx)

## Check Git {#tools-tab}

The **Tools** tab shows whether Git is available. Godot Launcher uses this check to enable Git initialization in Create Project and Project Settings.

[Git Tool Detection](./tools.mdx)

## Manage launcher updates {#updates-tab}

The **Updates** tab controls background update checks, prerelease updates, manual checks, skipped versions, and update installation prompts.

[Manage Godot Launcher Updates](../updates/manage-launcher-updates.mdx)
