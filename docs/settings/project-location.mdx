# Project Location Settings

The **Projects** tab in Godot Launcher Settings controls the default folder
for new projects.

## Project Location

**Project Location** sets the base directory for newly created projects.

To change this location, select **Browse** and choose a folder in the system
folder picker. The path field is read-only.

- Existing projects already added to the launcher are not moved.
- You can change this path at any time without changing existing project data.
- When creating a project, you can set a different **Project location** for that project only.

:::info
Changing the default project location affects only new projects created through Godot Launcher.

Adding existing projects will not move them into this folder.
:::

## Create one project somewhere else

In the **New Project** dialog, edit **Project location** or use its folder button to choose a different base folder for that project. The project name is added to the path automatically.

After changing or clearing the path, select **Use default location** to restore the default project folder. This choice affects only the project you are creating.

See [Creating a Project](../projects/create-project.mdx) for the full project creation flow.
