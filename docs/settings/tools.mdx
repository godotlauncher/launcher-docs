# Tool Settings

The **Tools** tab shows the command-line tools used by Godot Launcher. Git and Git LFS each show their availability, validated executable path, and version.

## Check Git

When the status is **Available**, Godot Launcher can use the Git installation shown on this page.

When Git is available, Godot Launcher can:

- Initialize Git while [creating a project](../projects/create-project.mdx).
- Initialize Git for an existing project from [Project Settings](../projects/project-settings.mdx#source-control).
- Clone a public Git or connected GitHub repository through [Add Project](../projects/import-repository.mdx).
- Show Git status on project cards.

Godot Launcher does not install Git. See [Installing Git](../tools/install-git.md) to add it.

## Check Git LFS

When Git LFS is **Available**, Godot Launcher can configure it while creating a new Git repository. The Git LFS option remains unavailable until both Git and Git LFS are ready.

Godot Launcher does not install or update Git LFS. Install it through your operating system or from the [Git LFS project](https://git-lfs.com/), then rescan the tools. See [Creating a Project](../projects/create-project.mdx#set-up-git) for the new-project workflow.

## Rescan tools

Select the rescan button beside a tool after you install, move, or update it. The tool drawer shows the executable path and version that Godot Launcher validated.

## Manage Git identities

Open Git from the **Tools** tab to manage two separate identity sources:

  className="docs-media-frame"
  alt="Git settings with installation details and identity controls"
  sources={{
    light: '/img/screenshots/screen_settings_git_identity_light.webp',
    dark: '/img/screenshots/screen_settings_git_identity_dark.webp',

/>

- **Global Git identity** writes `user.name` and `user.email` to Git's global configuration. Git uses these values when a repository has no local override.
- **Project identity preset** is saved by Godot Launcher. It does not change Git on its own. The launcher can suggest it during project creation or apply it as a repository-local identity before the first commit.

Enable **Use automatically for new repositories** if every new repository created by Godot Launcher should receive the preset without another identity prompt. Leave it disabled to review the preset whenever you create a project.

You can edit the preset even when Git is unavailable. Global identity controls remain unavailable until Godot Launcher can validate Git again.

Code editor detection is managed separately. Use [Code Editor Settings](./code-editors.mdx) to rescan Visual Studio Code or VSCodium and configure custom executable paths.

If Git remains unavailable, see [Troubleshooting](../troubleshooting.md#git).
