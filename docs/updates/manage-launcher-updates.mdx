# Update Godot Launcher {#manage-godot-launcher-updates}

Godot Launcher checks for updates automatically by default. You choose when to download an update and restart to install it.

<a id="where-to-manage-updates"></a>
<a id="automatic-checks-vs-manual-updates"></a>

## Check for an update {#checking-for-updates}

1. Open **Settings > Updates**.
2. Select **Check for updates**.
3. Wait for the result. If a newer version is available, select **Download update** to download it or **Skip this version** to dismiss it.

To check only when you choose, turn off **Automatically check for updates**. Automatic checks do not download or install updates.

## Download and install {#update-ready-to-install}

After you select **Download update**, progress appears in **Settings > Updates** and in the sidebar banner. When the download finishes, select **Restart now** in either location to restart Godot Launcher and install the update.

## Skip a version

Select **Skip this version** to stop background checks from prompting you about that release. Newer versions can still be offered.

<a id="manual-override-after-skipping"></a>

To install a skipped version, select **Check for updates** in **Settings > Updates**. A manual check can offer the skipped release again. To remove the saved skip choice and allow background reminders for it, select **Unskip skipped update**.

## Beta updates {#prerelease-updates}

Stable releases are offered by default. Enable **Receive beta updates** in **Settings > Updates** to include beta builds, which may be less stable. Turn it off to return future checks to stable releases; this does not downgrade the version already installed.

## Manual updates on rpm-ostree {#manual-update-required-on-rpm-ostree}

On rpm-ostree Linux systems, Godot Launcher can check for updates but cannot install them through the app. Select **Open download page**, then download and install the appropriate package manually. You can still use **Skip this version** when the update's version is shown.

## Errors and retry

If a download or installation error appears, select **Retry** in the sidebar banner to try downloading again. To check for an update again, use **Check for updates** in **Settings > Updates**.

If updating through the app continues to fail, download and install the appropriate package from the [Godot Launcher download page](https://godotlauncher.org/download/).
