# Godot Launcher 1.13.0-beta.2

This beta includes changes made since 1.12.0.

## New

- Manage shared Official export templates, choose the files to install, and import named TPZ builds for individual projects. Move Official and imported template storage independently to another folder or drive.
- Organise projects with coloured tags and filter by any selected tag alongside text search.
- Browse projects in a single-line **List** view alongside **Compact** and **Cards**, with direct actions, tags and editor versions.
- Enable **Launch in terminal** in **Project Settings > Launch** to keep Godot output and errors visible after the editor exits. The choice is saved per project and is off by default.
- Choose **Close to system tray** or **Quit Godot Launcher** in **Settings > Behavior > Window Close**. Closing to the tray remains the default.

## Improved

- Remove the New badge beside Connections in the sidebar.
- Select several installed editors and remove them with one confirmation. **Select unused editors** helps find launcher-managed editors that no registered project uses.
- Open the compact sidebar update panel to read release notes, follow download progress and choose when to restart and install. Closing the panel preserves an active download or ready update.
- Visible template views and open build selectors refresh when you return to the launcher window, preserving expanded folders and unsaved file selections.

## Fixed

- Catalogue refreshes pick up supported desktop editor assets added later to recent Godot releases, including later platform and Standard/.NET uploads.

## Using this beta

Enable **Receive beta updates** in **Settings > Updates** to receive beta builds. Turning it off returns future checks to stable releases; it does not downgrade an installed beta.

Existing project-local export templates stay in place until you choose a migration option and select **Apply changes**. Before applying a choice, you can select **Finish later** to leave them unchanged. The options let you add files to shared Official templates, save them as a named imported build, or remove them and use the shared collection.

After you apply a migration, the project uses the shared or imported templates and its local copies are removed. To keep the originals as a backup, make a separate copy before applying your choice. Changes you make to a shared Official collection affect every project using that version and edition.

Godot's **Reload Current Project** may disconnect terminal output. Reopen the project through Godot Launcher to start a new terminal session.
