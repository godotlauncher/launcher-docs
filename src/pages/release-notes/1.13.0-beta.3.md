# Godot Launcher 1.13.0-beta.3

## New

- The export template library supports shared **Official** collections, individual file selection, named TPZ imports, separate storage locations and a migration wizard for existing project templates.
- Coloured tags organise projects, with tag filters alongside text search.
- **List** adds a single-line project view alongside **Compact** and **Cards**, with tags, editor versions and direct actions.
- Godot can launch in a terminal, keeping output and errors visible after the editor exits.
- Choose whether closing the launcher window quits the application or sends it to the system tray.
- Bulk editor removal includes **Select unused editors** for launcher-managed versions that no registered project uses.
- A compact sidebar update panel brings release notes, download progress and installation actions together.

## Fixed

- Catalogue refreshes pick up supported desktop editor builds added later to recent Godot releases.

## Notes

**Share templates** and **Use shared templates** permanently remove local files. **Share templates** keeps existing shared files when names conflict. Keep a separate copy if you need a backup. Changes to a shared Official collection affect every project using that version and edition.

Godot's **Reload Current Project** may disconnect terminal output. Reopen the project through Godot Launcher to start a new terminal session.
