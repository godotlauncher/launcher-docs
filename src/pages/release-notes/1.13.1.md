# Godot Launcher 1.13.1

## 1.13.1

Godot Launcher 1.13.1 fixes macOS editor downloads for releases with separate Intel and Apple Silicon builds, starting with Godot 4.8 beta 1.

### Fixed

- Standard and .NET editor downloads now match your Mac's processor. Existing release listings are corrected automatically, while older universal downloads remain supported.

### Action required

Updating Godot Launcher does not replace editors you already installed. If you installed an incompatible build, remove the affected editor from **Installs**, then install it again after updating. See [Install a Godot Editor](/getting-started/install-editor/) for installation and removal guidance.

Godot 4.8 beta 1's .NET edition requires the .NET SDK 10.0 or newer. See [Godot's release announcement](https://godotengine.org/article/dev-snapshot-godot-4-8-beta-1/#downloads).

## 1.13.0

Godot Launcher 1.13.0 adds shared export templates and more ways to organise and launch projects.

### New

- The export template library supports shared **Official** collections, individual file selection, named TPZ imports and separate storage locations. A migration wizard lets you review existing templates per project or version, keep custom files, share them or decide later.
- Coloured tags organise projects, with tag filters alongside text search.
- **List** adds a single-line project view alongside **Compact** and **Cards**, with tags, editor versions and direct actions.
- Godot can launch in a terminal, keeping output and errors visible after the editor exits.
- Choose whether closing the launcher window quits the application or sends it to the system tray.
- Bulk editor removal includes **Select unused editors** for launcher-managed versions that no registered project uses.
- A compact sidebar update panel brings release notes, download progress and installation actions together.

### Improved

- Export template downloads can use the full package when individual files are unavailable. Interrupted moves and failed migrations offer recovery and retry controls.
- The **Connections** sidebar entry no longer displays the **New** badge.

### Fixed

- Catalogue refreshes pick up supported desktop editor builds added later to recent Godot releases.

### Notes

**Share templates** and **Use shared templates** permanently remove local files without saving a separate copy. **Share templates** keeps existing shared files when names conflict. Keep your own copy before choosing either option if you may need those originals. Changes to a shared Official collection affect every project using that version and edition.

Godot's **Reload Current Project** may disconnect terminal output. Reopen the project through Godot Launcher to start a new terminal session.
