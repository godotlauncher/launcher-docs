# Godot Launcher 1.14.0

Godot Launcher 1.14.0 adds new ways to import, duplicate, organise and run projects, plus terminal commands for installed Godot editors.

## New

- Duplicate an existing project into an independent copy. Choose a destination, optionally copy editor preferences or game save data, and start fresh Git history or publish to a private GitHub repository.
- Scan a folder for existing Godot projects or import projects already registered with Godot Project Manager. Review names, editor choices and tags before adding them; source projects stay in their current folders.
- Choose an installed editor as the default `godot` terminal command, and create a named command for each editor. Enable automatic alias creation for new installations under **Settings > Command line**, or create missing aliases for selected installed editors.
- Run a project's main scene directly from its actions menu, with guidance when a main scene or editor is unavailable.
- Select several projects to change tags, clear New status, pin or unpin them, or remove them from the project list together.
- The new **Extensions** page previews upcoming ways to extend and customise Godot Launcher, with a link to join the community discussion. Extensions are not available yet. GitHub connections remain under **Settings > Connections**.

## Improved

- Choose tags while creating, duplicating or importing projects, including shared tag changes for selected projects during an import.
- Set the order of Pinned, New and Recents. Clear a project's New status with an Undo notification; imported projects appear in Recents.
- Open pinned projects from the system tray in your chosen order, with additional pins under **More...** and recent projects below.
- Open a project's configured code editor directly, or let it open alongside Godot. Automatic code-editor opening is on by default for new preferences; existing saved choices are respected.
- Cancel editor downloads from Projects and Create Project as well as Installs, and stop export-template downloads beside their progress bars. Choose whether an import downloads missing editors, while keeping project choices available for retry.
- Find a newly duplicated project with automatic scrolling and a brief highlight. Folder imports show a progress bar and project count, and long review lists keep their actions visible.
- Refreshing the Godot release cache retains the previous list if the refresh fails. Release candidates use consistent ordering when choosing an editor.

## Fixed

- Prerelease editor aliases include their stage and number: `4.8-beta1` suggests `godot48b1`, beta2 suggests `godot48b2`, dev builds use `d`, alpha builds use `a`, and release candidates use `rc`. Manual suggestions, automatic installation aliases and bulk creation use this naming.
- Godot error messages appear as warnings without falsely claiming that a running project has failed. Startup failures and unsuccessful exits retain their own recovery messages.
- Restore the intended colours and flat controls in the Light theme.
- Improve Linux AppImage compatibility when launching Godot and external tools.

## Notes

Existing aliases keep their names; rename an older prerelease alias manually if you want the new convention. Standard and .NET editions of the same version can still need different names. Terminal commands use the editor's normal preferences; opening projects from Godot Launcher uses separate per-project preferences.

Running a project does not import assets, compile C# code or configure its main scene. Open the project in Godot first when those steps are needed.
