# Godot Launcher 1.14.0

Godot Launcher 1.14.0 adds more ways to bring in projects, keep them organised and launch them from the launcher or a terminal.

## New

- Duplicate a project into an independent copy, with the option to keep its editor preferences and game save data.
- Add existing projects by scanning a folder or importing them from Godot Project Manager.
- Choose a default Godot editor for your terminal, or give installed editors their own commands, including separate commands for prerelease versions and .NET editors.
- Run a project's main scene directly from its actions menu.
- Organise several projects at once: change tags, pin or unpin them, clear their **New** status, or remove them from the list.

## Improved

- Choose tags as you create, duplicate or import projects.
- Arrange the **Pinned**, **New** and **Recents** groups in your preferred order.
- Access pinned projects from the system tray in your chosen order, ahead of recent projects.
- Open a project's code editor directly or automatically alongside Godot.
- Cancel editor and export-template downloads wherever their progress is shown.
- Follow folder import progress and find newly duplicated projects with a brief highlight.
- Refresh available Godot versions while creating a project or changing its editor, without losing your selection.

## Fixed

- Changing editors no longer briefly opens an unrelated export-template migration window.
- Restored the intended colours and flat controls in the Light theme.
- Improved Linux AppImage compatibility when launching Godot and external tools.

## Notes

- Terminal commands use Godot's normal preferences; projects opened from Godot Launcher use separate per-project preferences.
- Open a project in Godot first if it needs assets imported, C# code compiled or a main scene configured before running.
- The **Extensions** page links to Discord to discuss ideas for extending Godot Launcher.
