# Godot Launcher Documentation

**Godot Launcher** is an independent desktop companion for Godot Engine. Use it to install Godot editors, organize projects, prepare Git, and choose a code editor for each project.

## What you can manage

- **Editor installs**: Download official Godot releases and register custom-built Godot editors.
- **Projects**: Create or add projects, organize them, and choose a Godot editor for each one.
- **Development tools**: Prepare Git and use Visual Studio Code or VSCodium for project scripts.
- **Project-specific settings**: Keep Godot editor settings isolated across projects and editor versions.
- **Launcher behavior**: Configure appearance, language, startup behavior, system tray access, update checks, and tool detection.
- **Platform options**: Use winget on Windows, optional Windows editor links, and the system tray when available.
