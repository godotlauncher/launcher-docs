# Project Tool Settings

Git and code editor choices now live in **Project Settings** instead of the project overflow menu.

## Current controls

- Open **Project Settings > Source Control** to initialize Git for an existing project.
- Open **Project Settings > Code Editor** to select Visual Studio Code, VSCodium, or **None**.
- Open **Settings > Code Editors** to manage detection, defaults, executable paths, and launch arguments.

See [Project Settings](./project-settings.mdx), [Code Editor Settings](../settings/code-editors.mdx), and [Using Git With Godot Launcher](../tools/using-git-with-godot-launcher.mdx) for details.
