# Godot Launcher Documentation

**Godot Launcher** is an independent desktop companion for Godot Engine. Use it to install Godot editors, organise projects, prepare Git, and choose a code editor for each project.

## Start here

[Install Godot Launcher](./getting-started/installation.mdx), then choose how to bring in your work:

- [Create a Godot project](./projects/create-project.mdx). Choose an editor during creation; Godot Launcher downloads it if needed.
- [Add an existing local project](./projects/add-existing-project.mdx).
- [Import a project from GitHub or a public Git URL](./projects/import-repository.mdx).

## Common tasks

- [Install a Godot editor](./editors/install-editor.mdx) or [register a custom build](./editors/custom-editors.mdx).
- [Change a project's Godot version](./editors/change-project-editor.md).
- [Manage Godot export templates](./editors/export-templates.mdx).
- [Organise and find projects](./projects/manage-projects.mdx).
- [Launch Godot in a terminal](./projects/launch-godot-in-terminal.mdx).
- [Update Godot Launcher](./updates/manage-launcher-updates.mdx).
- [Troubleshoot a problem](./troubleshooting.md).

## Settings and development tools {#what-you-can-manage}

- [Godot Launcher settings](./settings/launcher-settings.mdx) control appearance, language, storage locations, startup, and tool detection.
- [Godot editor settings per project](./editors/editor-settings.mdx) keep preferences separate and let you import or export them.
- [Git setup](./tools/using-git-with-godot-launcher.mdx) covers repositories, Git LFS, and commit identity.
- [Code editor settings](./settings/code-editors.mdx) control detection and defaults. See the [Visual Studio Code](./tools/vscode-setup.md) or [VSCodium](./tools/vscodium-setup.md) guide for project setup.
